Corralai is the **accountability layer for AI agents** — run a herd across any
model, contained and attributed, and certify what they ship by running the actual
check, with a human at the gate. New here? Read [**AI
accountability**](/docs/concepts/accountability/) for what that means, then
[Getting started](/docs/getting-started/) to install and run the key-free demo — or
jump straight to a topic in the sidebar.
