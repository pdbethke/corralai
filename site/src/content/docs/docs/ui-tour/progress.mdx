<aside class="callout callout-note">
<p class="callout-title">The optional daemon — frozen, and not read by any audit</p>

This page describes the **brain**, corral's optional coordination daemon. It is frozen: shipped and supported, but no longer developed and not on the path an audit takes. Nothing on it is required for a verdict: `corral certify --local` and `--repo`, `corral review`, the GitHub Action, `verify`, `ui`, `seal` and `scans` never contact a brain. And nothing on it is read by an audit — an audit's prompts are built from the goal, the code and its symbols, never from the daemon's shared memory or skills. See [the brain, and what it is not](https://github.com/pdbethke/corralai/blob/main/docs/corral/brain.md).

</aside>

The Progress tab lists every audit run — running or done — with its full
shard queue underneath, grouped by function and colored by status. This is
the same queue [claims and verify](/docs/concepts/queue-and-verify/) act on:
for an audit run on the brain, a shard is one mutant-generator seat's
slice of the file (a group of functions, balanced by complexity); a shard
shown as "claimed" is being planted, mutated, and run against the dev suite
right now, and one shown as "pending" is waiting for a free seat.
